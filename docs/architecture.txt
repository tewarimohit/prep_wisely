KEY DESIGN PRINCIPLES:
• Schema-First: Prisma schema → Zod contracts → TypeScript types
• User-in-Loop AI: AI suggests, user decides (no silent writes)
• Fail-Closed Safety: Zod validation + fallback system
• Optimistic UI: Instant feedback + server reconciliation
• Type Safety: End-to-end from database to UI
